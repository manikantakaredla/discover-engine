# Discover Engine 🚀

Discover Engine is a next-generation, AI-powered e-commerce search and recommendation platform built for the ultimate hackathon demonstration. It replaces traditional keyword search with deep semantic understanding, intent detection, and personalized real-time feeds.

## 🌟 Project Overview
Traditional e-commerce platforms force users to speak "computer" (e.g., "shoes running black size 10"). Discover Engine allows users to speak human (e.g., "I need something comfortable for my marathon training"). Our two-tower semantic architecture understands the *intent* behind the query, retrieves vector-embedded products, applies real-time business guardrails, and renders a dynamic, highly personalized feed.

## 🏗 Architecture
- **Frontend:** React, Vite, TailwindCSS, Lucide Icons (Premium UI, localized for India: `₹`, `UK` sizes)
- **Backend:** Node.js, Express, MongoDB (Mongoose)
- **AI Core:** Google Gemini 3.6 Flash (Intent Detection & Guardrails), Gemini Embedding 2 (Vector Embeddings)
- **Search Engine:** Hybrid Vector Search (Cosine Similarity) with robust Text & Category boosting fallbacks.

## ✨ Features
- **Semantic Search:** Finds products based on meaning, not just exact keyword matches.
- **Robust Fallback Engine:** Automatically degrades gracefully to Text/Category matching if AI quotas are exceeded.
- **Explainable AI:** Transparent UI showing *why* a product was recommended.
- **Real-time KPI Dashboard:** Admin view showing execution trace, system latency, cache hits, and CTR metrics powered entirely by actual database metrics (zero dummy data).
- **Event Tracking Pipeline:** Tracks page views, searches, and recommendation clicks asynchronously using localized session identifiers.
- **300+ Product Catalog:** Database perfectly seeded with 300 premium items spanning diverse categories for high-quality recommendations.

## 🚀 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-repo/discover-engine.git
   cd discover-engine
   ```

2. **Backend Setup:**
   ```bash
   npm install
   npm run dev
   ```

3. **Frontend Setup:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

4. **Seed the Database (300 Products):**
   ```bash
   node seed_large_catalog.cjs
   ```

## 🔐 Environment Variables
Create a `.env` file in the root directory:
```env
PORT=5000
MONGODB_URI=mongodb+srv://<user>:<password>@cluster0.mongodb.net/discover-engine
GEMINI_API_KEY=your_gemini_api_key
```

## 🎥 Demo Flow (Golden Path)
1. **Home Page:** User lands on the beautifully curated catalog.
2. **Semantic Search:** User searches "running shoes" or "black bag".
3. **Intent Detection:** Gemini extracts the underlying intent (e.g., Fitness Journey).
4. **Vector Retrieval:** Backend performs cosine similarity search. Even if the AI API is rate-limited, the system falls back to text/category boosting seamlessly.
5. **Complete The Look:** Highly relevant product recommendations are instantly generated by matching product categories dynamically.
6. **Admin Dashboard:** Hackathon judges view the live `Execution Trace`, pipeline latency, and KPI metrics ticking in real-time as events flow in.
